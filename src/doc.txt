TOKENIZER:
    this program cuts the source file into tokens. Its a simple while loop that read the file and uses the inline bool functions to identify the type of characters we have in the file. 

REPL:
    its a a expression parser that can handle variable and inbuild function by first creating an AST and then evaluating them using said ast. the variables persits over the session and are flushed out after closing the session via quit.
